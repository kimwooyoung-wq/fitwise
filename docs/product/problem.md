# Problem Statement

## 관찰한 문제

온라인 패션 쇼핑에서 사용자는 상품을 발견한 뒤에도 구매 결정을 위해 여러 화면을 오가야 한다.

- 자신의 상황에 적합한 상품인지 판단하기 어렵다.
- 브랜드마다 다른 사이즈 체계로 실제 착용감을 예상하기 어렵다.
- 자신과 비슷한 체형의 후기를 찾는 데 시간이 걸린다.
- 여러 상품을 동일한 기준으로 비교하기 어렵다.
- 개인화 추천이 제시된 이유와 한계를 알기 어렵다.

## 핵심 문제

사용자는 더 많은 추천보다 자신의 상황과 체형에 맞는 선택인지 판단할 수 있는 근거가 필요하다.

## 제품 가설

사용자의 목적, 체형, 예산과 유사 체형 리뷰를 결합해 추천 이유와 신뢰도를 제공하면 구매 결정 시간은 감소하고 선택 확신도는 높아질 것이다.

## 검증 질문

1. 사용자는 어떤 순간에 상품 탐색을 중단하거나 결정을 미루는가?
2. 사이즈를 선택할 때 가장 신뢰하는 정보는 무엇인가?
3. 체형이 비슷한 리뷰를 찾는 데 현재 얼마나 많은 노력이 필요한가?
4. 추천 이유와 신뢰도 표시는 실제 선택에 도움이 되는가?
5. 비교 기준을 직접 조정하는 기능은 결정 시간을 줄이는가?

## 초기 성공 지표

| 지표 | 정의 |
|---|---|
| 구매 후보 결정 시간 | 과제 시작부터 하나의 후보를 선택하기까지 걸린 시간 |
| 확인한 상품 수 | 결정 전 열어본 상품 상세 페이지 수 |
| 선택 확신도 | 과제 후 5점 척도로 측정한 주관적 확신 |
| 추천 근거 이해도 | 추천 이유를 올바르게 설명한 사용자 비율 |
| 결정 완료율 | 제한 시간 안에 하나의 후보를 선택한 사용자 비율 |

## 현재 가정

- 20~30대 온라인 패션 쇼핑 사용자를 첫 검증 대상으로 삼는다.
- 사용자는 상품 발견보다 선택과 사이즈 판단에서 더 큰 마찰을 경험한다.
- 추천 근거가 간결하고 구체적일수록 사용자의 신뢰가 높아진다.

이 가정은 사용자 인터뷰와 프로토타입 테스트를 통해 수정한다.

## MVP에서 제외할 범위

- 실제 결제와 주문 처리
- 실제 쇼핑몰 계정 연동
- 상용 서비스의 상품·리뷰 대량 수집
- AR 가상 착용
- 네이티브 모바일 앱
- 완전 자동화된 스타일 판단

## 데이터 원칙

- 사용 권한이 확인된 이미지와 공개 데이터만 사용한다.
- 테스트용 합성 데이터는 합성 데이터임을 표시한다.
- 신체 정보는 최소한으로 수집하고 사용 목적을 명확히 설명한다.
- 추천 결과를 사실처럼 단정하지 않고 신뢰도와 한계를 함께 제공한다.
