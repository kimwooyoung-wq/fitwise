# Competitive Analysis Framework

## Objective

경쟁 분석의 목적은 대형 패션 플랫폼의 기능을 복제하는 것이 아니다. 기존 서비스가 어떤 구매 문제를 해결하고 어디에서 사용자의 최종 판단을 충분히 돕지 못하는지 확인해 FITWISE를 반드시 사용할 이유와 사업 기회를 찾는다.

## Comparison set

국내외 서비스를 최소 6개 선정하되 다음 범주가 포함되도록 한다.

- 종합 패션 커머스
- 스타일·코디 중심 커머스
- 사이즈 또는 핏 추천 서비스
- 옷장 관리 또는 코디 서비스
- 가격·상품 비교 서비스
- 해외 개인화 패션 서비스

서비스 이름과 최신 기능은 조사 시점에 다시 확인하고 조사 날짜와 사용 환경을 기록한다.

## Common test scenario

모든 서비스에서 같은 과제를 수행한다.

```text
예산 15만 원으로 회사 워크숍에 입을 옷을 찾는다.
너무 격식 있지 않아야 하며 보유한 검은색 슬랙스와 조합해야 한다.
사이즈와 추천 이유를 확인하고 하나의 후보를 결정한다.
```

시작부터 후보 결정까지 화면 수, 이동 횟수, 필요한 외부 검색과 소요 시간을 기록한다.

## Evaluation criteria

| Criterion | Questions |
|---|---|
| Target problem | 탐색·사이즈·스타일·가격·비교 중 무엇을 해결하는가? |
| Intent input | 예산·장소·목적·취향을 한 번에 표현할 수 있는가? |
| Input burden | 추천 전에 사용자가 제공해야 하는 정보와 시간은 얼마인가? |
| Recommendation basis | 인기·구매 이력·체형·상황·보유 의류 중 무엇을 사용하는가? |
| Explainability | 추천 이유, 주의점과 데이터 한계를 보여주는가? |
| Fit support | 사이즈표를 넘어 추천 사이즈와 근거를 제공하는가? |
| Comparison | 여러 후보를 같은 기준으로 비교하고 기준을 조정할 수 있는가? |
| Wardrobe continuity | 구매 후 기존 옷과의 조합·중복·활용도를 지원하는가? |
| Platform dependence | 자사 상품만 다루는가, 외부 후보도 비교할 수 있는가? |
| Trust and privacy | 신체·옷장 데이터의 목적, 보관과 삭제 방법이 명확한가? |
| Retention loop | 사용자가 다음 구매에도 돌아올 이유가 무엇인가? |
| Business model | 광고·판매 수수료·구독·B2B 중 무엇으로 수익을 만드는가? |

각 기준은 `지원하지 않음 / 제한적 / 충분함`으로 평가하고 관찰 근거와 화면을 함께 기록한다. 근거 없이 하나의 종합 점수로 순위를 만들지 않는다.

## Differentiation questions

분석 후 다음 질문에 한 문장으로 답한다.

1. 기존 서비스가 가장 잘 해결하는 일은 무엇인가?
2. 사용자가 여전히 다른 화면이나 서비스로 이동하는 순간은 언제인가?
3. FITWISE가 같은 기능을 더 만드는 대신 새롭게 연결할 결정 단계는 무엇인가?
4. 어떤 데이터가 쌓일수록 FITWISE의 결과가 더 좋아지는가?
5. 경쟁사가 같은 기능을 추가해도 유지되는 차별점은 무엇인가?

## Business questions

- 상품 이동과 제휴 수수료가 사용자 신뢰와 충돌하지 않는가?
- 무료 추천과 유료 고급 기능의 경계는 어디인가?
- 옷장·체형 데이터가 반복 사용을 만들 만큼 충분한 가치를 주는가?
- 소비자용 기능 중 쇼핑몰이 비용을 지불할 B2B 기능은 무엇인가?
- 데이터 취득 비용, 상품 최신성, 지원해야 할 운영 업무가 수익보다 커지지 않는가?

## Required outputs

- 서비스 6개 이상, 동일 기준 10개 이상의 비교표
- 공통 테스트 시나리오의 단계·시간·외부 이동 기록
- 반복되는 미해결 문제 3개 이상
- FITWISE의 차별화 문장 1개와 반증 조건
- 초기 수익 모델 가설 1개, 후속 가설 최대 2개
- 프로토타입에서 검증할 사용자 행동과 측정 지표
