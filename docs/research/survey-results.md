# 설문 중간 분석 — 2026-10-12

> 상태: 응답 수집 중 · Google Forms 응답 21건 기준 · 최종 분석 예정일 2026-10-15

## 분석 원칙

- 원본 응답은 접근이 제한된 Google Forms에만 보관한다.
- GitHub와 Notion에는 이름, 이메일, 응답 원문과 개인을 추정할 수 있는 조합을 저장하지 않는다.
- 현재 표본은 21명으로 작고 편의표본이므로 시장 전체를 대표하지 않는다.
- 수집 종료 전 결과는 기능 확정이 아니라 다음 프로토타입의 검증 우선순위를 정하는 근거로 사용한다.

## 응답 요약

최근 6개월 내 온라인 의류 구매 경험이 있는 응답은 21명 전원이다.

| 질문 | 가장 큰 응답 | 다음 응답 | 해석 |
|---|---:|---:|---|
| 최근 6개월 구매 빈도 | 2~3회 10명(47.6%) | 7회 이상 5명(23.8%) | 저빈도와 고빈도가 함께 있어 구매 경험 수준을 구분한 후속 검증이 필요하다. |
| 결정까지 걸린 시간 | 1시간 이상·하루 이상 11명(52.4%) | 30분~1시간 4명(19.0%) | 응답자의 71.4%가 30분 이상 고민한다. 결정 시간 단축은 유효한 문제 가설이다. |
| 가장 어려운 판단 | 사이즈·핏 7명(33.3%) | 여러 후보 비교 6명(28.6%) | 첫 프로토타입은 사이즈 근거와 비교 흐름을 우선해야 한다. |
| 구매 확신도 | 4점 11명(52.4%) | 3점 4명(19.0%) | 평균 3.62/5이며 4~5점은 66.7%다. 불만이 극단적이지 않으므로 기존 방식보다 명확히 나은 근거가 필요하다. |
| 외부에서 한 행동 | 다른 쇼핑몰 비교 6명(28.6%) | 보유 의류·실측 비교 5명(23.8%) | 판단 근거가 한 화면에 모이지 않아 사용자가 직접 정보를 결합한다. |
| 가장 필요한 비교 정보 | 유사 체형 후기 7명(33.3%) | 보유 의류 조합·가격 할인 각 4명(19.0%) | Review Lens와 My Wardrobe를 연결할 근거가 있으나, 데이터 품질과 프라이버시가 선행돼야 한다. |

구매 상황 자유응답에서는 데이트·외출, 운동, 출근, 여행, 계절 변화, 일상 보충과 스타일 조합이 반복됐다. 원문은 공개 저장하지 않고 최종 분석에서 비식별 코드만 사용한다.

## 제품 결정

### 즉시 검증

1. **상황·예산 검색 → 3개 후보 비교**: 흩어진 탐색을 한 흐름으로 줄일 수 있는지 측정한다.
2. **사이즈·핏 근거 카드**: 평소 사이즈, 상품 실측, 유사 체형 신호와 데이터 부족 상태를 분리해 보여준다.
3. **보유 의류와의 조합**: 사진 업로드 없이도 카테고리·색상·핏 태그로 조합 가능성을 먼저 검증한다.
4. **추천 이유와 주의점**: 단일 점수보다 근거 출처와 불확실성을 보여준다.

### 추가 증거 필요

- 실제 색상·질감, 재고·배송 정보는 응답 우선순위가 낮지만 구매 실패 비용이 있으므로 후속 사용성 테스트에서 확인한다.
- 유사 체형 후기의 효과는 충분한 리뷰 데이터와 동의·익명화가 확보될 때만 구현한다.
- 구매 확신이 이미 높은 응답자에게 FITWISE가 추가 가치를 주는지 별도 검증한다.

### 현재 제외

- 결제, 주문, 반품과 ERP 전체 기능
- 사용권이 확인되지 않은 브랜드 상품·리뷰 수집
- 얼굴·전신 사진 기반 체형 추정
- AI가 가격, 재고, 실측과 후기를 생성하는 기능

## 다음 프로토타입 성공 기준

5명 이상의 과업 테스트에서 기존 방식과 FITWISE 흐름을 비교한다. 실행 절차와 비식별 기록 양식은 [5인 사용성 테스트 계획](usability-test-plan.md)을 따른다.

| 지표 | 임시 기준 |
|---|---|
| 결정 시간 | 동일 과업에서 기존 방식 대비 중앙값 감소 |
| 비교 효율 | 확인한 외부 페이지 또는 앱 수 감소 |
| 근거 이해 | 사용자가 추천 이유와 주의점 중 2개 이상 설명 |
| 사이즈 안전성 | 데이터가 부족한 경우 추천을 단정하지 않음 |
| 선택 확신 | 과업 전후 5점 척도 개선 여부 기록 |
