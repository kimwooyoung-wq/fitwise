# FITWISE 사용자 조사 설문지

## 목적

온라인에서 옷을 구매할 때 상품 발견 이후 실제 결정을 어렵게 만드는 요인과 현재 사용하는 해결 방법을 파악한다. 특정 기능의 선호도를 묻기 전에 최근 실제 구매 행동을 중심으로 조사한다.

## 권장 설정

- 예상 응답 시간: 5~7분
- 목표 유효 응답: 최소 30건, 권장 50건
- 로그인 요구: 사용하지 않음
- 이메일 자동 수집: 사용하지 않음
- 응답 수정: 사용하지 않음
- 결과 요약 공개: 사용하지 않음
- 이름·전화번호·정확한 신체 치수: 수집하지 않음
- 인터뷰 지원 연락처는 마지막 선택 문항에서만 별도로 수집하고, 설문 분석 데이터와 분리해 관리

## 제목

온라인 패션 쇼핑의 구매 결정 경험 조사

## 소개문

안녕하세요. 이 설문은 온라인에서 옷을 살 때 상품을 비교하고 사이즈를 선택하는 과정에서 어떤 어려움이 발생하는지 알아보기 위한 FITWISE 프로젝트 사용자 조사입니다.

응답은 제품 연구 목적으로만 사용하며, 개인을 식별할 수 있는 이름·정확한 신체 치수는 수집하지 않습니다. 선택 문항은 건너뛸 수 있습니다. 응답에는 약 5~7분이 걸립니다.

마지막에 후속 인터뷰 참여를 선택한 경우에만 연락처를 수집하며, 연락처는 인터뷰 섭외 후 삭제합니다.

## 문항

### 섹션 1 · 참여 조건

1. **최근 6개월 안에 온라인으로 의류를 구매한 경험이 있나요?** — 객관식, 필수
   - 예
   - 아니요
   - `아니요` 선택 시 종료 안내: “응답해 주셔서 감사합니다. 이번 조사는 최근 온라인 의류 구매 경험이 있는 분을 대상으로 합니다.”

2. **최근 6개월 동안 온라인으로 의류를 구매한 횟수는 어느 정도인가요?** — 객관식, 필수
   - 1회
   - 2~3회
   - 4~6회
   - 7회 이상

3. **연령대는 어떻게 되나요?** — 객관식, 선택
   - 19세 이하
   - 20~24세
   - 25~29세
   - 30~34세
   - 35~39세
   - 40세 이상
   - 응답하지 않음

### 섹션 2 · 최근 실제 구매 경험

4. **가장 최근 온라인으로 구매한 의류는 무엇이었나요?** — 단답형, 필수
   - 예: 셔츠, 청바지, 재킷

5. **그 옷이 필요했던 상황이나 목적은 무엇이었나요?** — 장문형, 필수
   - 예: 첫 출근, 여행, 일상복 교체

6. **상품을 처음 찾기 시작한 곳은 어디였나요?** — 객관식, 필수
   - 종합 패션 플랫폼
   - 브랜드 공식몰
   - 포털·검색 엔진
   - SNS·영상 콘텐츠
   - 오프라인에서 본 뒤 온라인 검색
   - 지인 추천
   - 기타

7. **구매를 결정하기 전에 몇 개 정도의 상품 상세 페이지를 확인했나요?** — 객관식, 필수
   - 1~2개
   - 3~5개
   - 6~10개
   - 11개 이상
   - 기억나지 않음

8. **구매 결정까지 얼마나 걸렸나요?** — 객관식, 필수
   - 10분 이내
   - 10~30분
   - 30분~1시간
   - 1시간 이상
   - 하루 이상 고민
   - 결국 구매하지 않음

9. **결정 과정에서 확인한 정보를 모두 선택해 주세요.** — 체크박스, 필수
   - 가격·할인
   - 상품 사진·영상
   - 소재·세탁 정보
   - 상품 실측
   - 모델 정보
   - 구매 후기
   - 나와 비슷한 체형의 후기
   - 코디 예시
   - 배송·반품 조건
   - 다른 플랫폼의 동일 상품
   - 이미 가진 옷과의 조합
   - 기타

10. **가장 판단하기 어려웠던 한 가지는 무엇이었나요?** — 객관식, 필수
    - 내 목적·상황에 어울리는지
    - 실제 색상·소재가 어떤지
    - 어떤 사이즈가 맞는지
    - 내 체형에서 어떤 핏이 나오는지
    - 가격 대비 가치가 있는지
    - 이미 가진 옷과 잘 어울리는지
    - 여러 후보 중 무엇이 더 나은지
    - 후기 중 무엇을 믿어야 하는지
    - 특별히 어렵지 않았음
    - 기타

11. **결정을 어렵게 만든 구체적인 순간이나 이유를 설명해 주세요.** — 장문형, 필수

12. **결정을 내리기 위해 앱이나 사이트 밖에서 한 행동이 있나요?** — 체크박스, 필수
    - 다른 쇼핑몰에서 가격 비교
    - 검색 엔진에서 추가 검색
    - SNS·영상 후기 검색
    - 지인에게 질문
    - 줄자나 가지고 있는 옷으로 실측 비교
    - 메모·스크린샷·장바구니로 후보 비교
    - 오프라인 매장 방문
    - 별도로 한 행동 없음
    - 기타

13. **가장 최근 구매 결정에 얼마나 확신이 있었나요?** — 선형 배율 1~5, 필수
    - 1: 전혀 확신하지 못함
    - 5: 매우 확신함

14. **구매 후 결과는 어땠나요?** — 객관식, 필수
    - 기대보다 좋았음
    - 대체로 기대와 같았음
    - 일부 아쉬웠지만 사용함
    - 교환함
    - 반품함
    - 아직 받지 못함
    - 구매하지 않음

### 섹션 3 · 현재 서비스와 필요한 근거

15. **현재 패션 플랫폼의 개인화 추천을 얼마나 신뢰하나요?** — 선형 배율 1~5, 필수
    - 1: 전혀 신뢰하지 않음
    - 5: 매우 신뢰함

16. **추천을 신뢰하거나 신뢰하지 않는 가장 큰 이유는 무엇인가요?** — 장문형, 필수

17. **구매 후보를 비교할 때 한 화면에서 가장 보고 싶은 정보 3가지를 선택해 주세요.** — 체크박스, 필수, 최대 3개
    - 총 가격·할인
    - 목적 적합도
    - 추천 사이즈와 근거
    - 나와 비슷한 체형의 후기 요약
    - 소재·관리 난이도
    - 가지고 있는 옷과의 조합 가능성
    - 예상 활용 빈도
    - 추천 이유와 주의점
    - 배송·반품 조건
    - 기타

18. **추천 결과에서 불확실하거나 데이터가 부족한 부분을 명확히 표시한다면 도움이 될까요?** — 선형 배율 1~5, 필수
    - 1: 전혀 도움 되지 않음
    - 5: 매우 도움 됨

19. **온라인 의류 구매 과정에서 꼭 해결되었으면 하는 문제가 있다면 자유롭게 적어 주세요.** — 장문형, 선택

### 섹션 4 · 후속 인터뷰

20. **30분 내외의 온라인 인터뷰에 참여할 의향이 있나요?** — 객관식, 필수
    - 예
    - 아니요

21. **인터뷰 참여를 선택했다면 연락받을 이메일 주소를 적어 주세요.** — 단답형, 선택
    - 설명: 인터뷰 섭외 목적으로만 사용하고 섭외 종료 후 삭제합니다.
    - 20번에서 `예`를 선택한 응답자에게만 표시

## 제출 완료 메시지

응답해 주셔서 감사합니다. 답변은 FITWISE의 문제 정의와 초기 제품 범위를 결정하는 데 사용됩니다. 인터뷰 참여를 선택한 분께는 입력한 이메일로 별도 연락드리겠습니다.

## 분석 계획

- 7번과 8번으로 현재 탐색 비용과 결정 시간의 기준선을 만든다.
- 10번을 핵심 문제별 빈도, 13번을 현재 선택 확신도의 기준선으로 사용한다.
- 9·12·17번을 교차 분석해 현재 우회 행동과 필요한 비교 근거를 연결한다.
- 11·16·19번은 행동·문제·현재 대안·신뢰 요인으로 코딩한다.
- 2·3번은 세그먼트 차이를 탐색하는 용도로만 사용하며, 작은 표본에서 일반화하지 않는다.
