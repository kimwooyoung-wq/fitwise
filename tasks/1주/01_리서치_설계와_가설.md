# [1주] 리서치 설계와 가설 정리

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-08 ~ 2026-10-14 |
| 단계 | Product Discovery |
| 이슈 | 미등록 |

## 목표

누구의 어떤 구매 결정을 개선할지, 어떤 질문으로 검증할지 명확히 한다.

## 필수 과제

- [ ] 20~30대 온라인 패션 구매자를 기준으로 모집 조건과 제외 조건 정의
- [ ] 30분 인터뷰 가이드 작성: 최근 구매 경험, 중단·미룬 순간, 사이즈 판단, 후기 탐색, 비교 방식
- [ ] 현재 가정을 검증 가능 문장으로 분해하고 우선순위·증거 수준 기록
- [ ] 성공 지표 5개에 대한 측정 시점과 계산식 초안 작성
- [ ] 개인정보·녹취 동의와 익명화 원칙 작성

## 선택 과제

- [ ] 인터뷰 모집 메시지와 사전 설문 작성
- [ ] 리서치 기록 템플릿 작성
