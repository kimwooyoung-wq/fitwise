# [1주] 리서치 설계와 가설 정리

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-08 ~ 2026-10-14 |
| 단계 | Product Discovery |
| 이슈 | [#1](https://github.com/kimwooyoung-wq/fitwise/issues/1) |

## 목표

누구의 어떤 구매 결정을 개선할지, 어떤 질문으로 검증할지 명확히 한다. 동시에 대형 패션 플랫폼의 기능을 나열하는 데 그치지 않고 FITWISE가 책임질 핵심 도메인과 기업급 품질 기준을 정의한다.

## 필수 과제

- [ ] 20~30대 온라인 패션 구매자를 기준으로 모집 조건과 제외 조건 정의
- [ ] 설문 종료 후 분석 순서와 판단 기준을 `docs/research/survey-follow-up-plan.md`에 작성
- [ ] 현재 가정을 검증 가능 문장으로 분해하고 우선순위·증거 수준 기록
- [ ] 사용자 가치·차별화·재방문·사업성 가설을 분리하고 각 가설의 검증 행동 정의
- [ ] 사용자 가치 지표 5개와 초기 사업성 지표 1개 이상의 측정 시점·계산식 초안 작성
- [ ] 설문 응답의 익명화·보관·공개 범위 원칙 작성
- [ ] 대형 패션 플랫폼 5개 이상을 상품 탐색·사이즈·리뷰·추천 설명·비교·개인정보·운영 신뢰성 기준으로 조사할 평가표 설계
- [ ] 설문 문항을 검토하고 Google Forms로 공개해 유효 응답 30건 이상 모집 시작
- [ ] 1인 개발에서 줄일 범위와 유지할 품질 기준을 `docs/product/solo-enterprise-scope.md`에 명시
- [ ] 자연어 검색부터 구매 후 옷장 분석까지의 제품 루프와 단계별 수익 가설 문서화

## 선택 과제
