# [10주] 프로필과 체형·선호 온보딩

| 항목 | 내용 |
|---|---|
| 기간 | 2026-12-10 ~ 2026-12-16 |
| 단계 | Foundation |
| 이슈 | 미등록 |

## 목표

추천에 필요한 최소 정보만 수집하고 사용자가 언제든 확인·수정·건너뛸 수 있게 한다.

## 필수 과제

- [ ] 체형·평소 사이즈·스타일 선호·회피 조건 입력 UI 구현
- [ ] 필수와 선택 정보를 구분하고 수집 목적 설명
- [ ] 건너뛰기와 나중에 입력하기 지원
- [ ] 프로필 조회·수정·삭제 API 구현
- [ ] 입력 검증과 오류·로딩·저장 상태 구현
- [ ] 모바일 키보드와 폼 접근성 점검

## 선택 과제

- [ ] 프로필 완성도가 추천 신뢰도에 미치는 영향 미리보기

## 산출물

- 온보딩·프로필 편집 화면과 API
- 프로필 도메인 테스트
- `docs/product/profile-data-policy.md`

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 최소 수집 | 선택 정보 없이도 온보딩 완료 가능 | E2E 테스트 |
| 투명성 | 각 민감 정보에 사용 목적이 표시됨 | UI 검토 |
| 편집 | 저장 후 재접속해 값이 유지되고 삭제 가능 | 통합 테스트 |
| 접근성 | 레이블·오류 연결·키보드 이동이 정상 | 자동/수동 점검 |
