## 목표

핵심 흐름이 설명 없이 이해되는지 검증하고 구현 설계를 확정한다.

## 필수 과제

- [ ] 참가자 5명에게 동일한 구매 결정 과제 수행 요청
- [ ] 과제 성공률, 시간, 오류, 질문, 선택 확신도 측정
- [ ] Think-aloud 관찰과 사후 인터뷰 기록
- [ ] 문제를 심각도·빈도·수정 비용으로 우선순위화
- [ ] 치명적 문제 수정 후 2명 이상 재검증
- [ ] 구현용 화면·상태·문구 명세 확정

## 선택 과제

- [ ] 기존 쇼핑 방식과 프로토타입의 결정 시간 비교
