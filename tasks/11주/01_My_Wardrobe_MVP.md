## 목표

사용자가 보유 의류를 빠르게 등록하고 추천 요청에 사용할 옷을 선택할 수 있게 한다.

## 필수 과제

- [ ] 카테고리·색상·핏·소재·계절·착용 빈도 데이터 모델 구현
- [ ] 사진 없이 1분 안에 옷 1개를 등록하는 기본 흐름 구현
- [ ] 목록·필터·수정·삭제 구현
- [ ] 추천 요청에서 기준 옷을 선택하는 기능 구현
- [ ] 사진 업로드는 선택 사항으로 분리하고 저장 정책 표시
- [ ] 조합 가능성 계산을 위한 표준 태그 정의

## 선택 과제

- [ ] 최근 등록값 기반 빠른 태그 제안

## 산출물

- My Wardrobe 화면·API·DB
- `docs/product/wardrobe-taxonomy.md`
- CRUD와 권한 테스트

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 속도 | 사진 없이 필수 정보로 1분 안에 등록 가능 | 3회 수행 평균 |
| 관리 | 등록·조회·수정·삭제·필터 동작 | E2E 테스트 |
| 권한 | 다른 사용자의 옷장에 접근 불가 | 통합 테스트 |
| 추천 입력 | 선택한 옷 ID와 표준 태그가 추천 요청에 전달 가능 | API 테스트 |
