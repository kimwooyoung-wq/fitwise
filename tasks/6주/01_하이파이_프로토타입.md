# [6주] 하이파이 프로토타입

| 항목 | 내용 |
|---|---|
| 기간 | 2026-11-12 ~ 2026-11-18 |
| 단계 | Prototype |
| 이슈 | 미등록 |

## 목표

실제 문구와 데이터 예시를 사용해 사용성 테스트가 가능한 모바일 프로토타입을 만든다.

## 필수 과제

- [ ] 비주얼 시스템의 색상·서체·간격·상태 토큰 정리
- [ ] 목적 입력, 프로필, 옷장 선택, 추천, 근거, 비교, 결정 화면 제작
- [ ] 실제 길이의 한국어 문구와 합성 상품·리뷰 데이터 사용
- [ ] 추천 이유와 주의점이 점수보다 먼저 이해되도록 정보 위계 검토
- [ ] 클릭 가능한 핵심 흐름 연결

## 선택 과제

- [ ] 데스크톱 비교 보드 반응형 시안

## 산출물

- Figma 하이파이 프로토타입 링크
- 갱신된 `docs/design/visual-system.md`
