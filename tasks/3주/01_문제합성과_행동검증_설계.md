# [3주] 문제 합성과 행동 검증 설계

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-22 ~ 2026-10-28 |
| 단계 | Product Discovery |
| 이슈 | 미등록 |

## 목표

설문과 경쟁 서비스 동일 과업 관찰을 합쳐 가장 해결 가치가 높은 문제를 선택하고, 추측이 아니라 사용자 행동으로 검증할 5인 비교 과업을 확정한다.

## 필수 과제

- [ ] 설문 주장과 경쟁 서비스 관찰을 문제별로 연결
- [ ] 관찰, 해석, 가설을 분리해 근거 수와 반대 사례 기록
- [ ] 문제별 빈도·심각도·현재 대안·해결 가능성 평가
- [ ] 우선 문제 1개와 보조 문제 최대 2개 선택
- [ ] 첫 사용자와 대표 구매 상황을 한 문장으로 고정
- [ ] 기존 방식과 FITWISE 프로토타입의 동일 비교 과업 작성
- [ ] 결정 시간·완료율·외부 이동·근거 이해도·과신 측정 방법 확정
- [ ] 개인정보가 없는 참가자 코드와 기록표, 중단 기준 작성

## 선택 과제

- [ ] 핵심 해석이 충돌할 때만 10~15분 확인 인터뷰 진행
- [ ] 문제를 크게 느끼지 않는 반대 사례 1명 확인

| 선택 | 우선 문제와 선택하지 않은 문제의 이유·반증 조건이 있음 | 결정 기록 검토 |
| 과업 | 기존 방식과 프로토타입이 같은 목표·조건을 사용함 | 테스트 계획 검토 |
