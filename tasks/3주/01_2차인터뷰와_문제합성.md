## 목표

인터뷰 표본을 넓히고 가장 자주 발생하면서 해결 가치가 높은 문제를 선택한다.

## 필수 과제

- [ ] 1차에서 부족했던 사용자 유형을 포함해 인터뷰 5명 추가
- [ ] 누적 10명의 행동·동기·불편·현재 대안을 친화도 방식으로 분류
- [ ] 문제별 빈도·심각도·현재 대안 만족도·해결 가능성 평가
- [ ] 우선 문제 1개와 보조 문제 최대 2개 선택
- [ ] 주요 사용자 여정과 결정이 지연되는 순간을 시각화

## 선택 과제

- [ ] 반대 사례 또는 문제를 느끼지 않는 사용자 1명 추가 인터뷰
