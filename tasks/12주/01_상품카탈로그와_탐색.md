# [12주] 상품 카탈로그와 탐색

| 항목 | 내용 |
|---|---|
| 기간 | 2026-12-24 ~ 2026-12-30 |
| 단계 | Foundation |
| 이슈 | 미등록 |

## 목표

권리 문제가 없는 데이터로 검색·필터·추천 엔진이 사용할 상품 후보 집합을 만든다. 작은 허가 카탈로그에서 시작하되 공식 브랜드 피드와 판매처 API를 추가할 수 있는 수집 경계를 확립한다.

## 필수 과제

- [ ] 상품·옵션·사이즈 실측·가격·재고·스타일 태그 스키마 구현
- [ ] 합성 또는 사용 허가가 확인된 상품 200개 이상 seed
- [ ] product·variant·size_measurement·offer·source_record 경계 구현
- [ ] CSV 원본 보존·검증·정규화·격리·upsert 파이프라인 구현
- [ ] 공급처 ID·체크섬 기반의 멱등성과 상품 변경·품절 처리
- [ ] 카테고리·가격·사이즈·스타일·재고 필터 구현
- [ ] 텍스트 검색과 페이지네이션 구현
- [ ] 데이터 출처·합성 여부·관찰 시각·사용 범위 표시
- [ ] 검색 등급과 사이즈·핏 판단 등급 데이터 분리
- [ ] 후보 검색 API 계약과 성능 기준 작성

## 선택 과제

- [ ] Google Merchant 호환 피드 어댑터 초안
- [ ] PostgreSQL 전문 검색과 단순 태그 검색 비교

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 데이터 | 200개 이상, 필수 필드 누락 0건 | seed 검증 |
| 수집 | 같은 배치를 재처리해도 중복이 없고 잘못된 행은 격리됨 | 통합 테스트 |
| 필터 | 조합 필터가 명세와 동일한 결과 반환 | API 테스트 |
| 사실성 | 가격·재고·실측이 생성형 출력에서 오지 않음 | 코드 리뷰 |
| 최신성 | 만료·품절 offer가 추천 후보에서 제외됨 | 동기화 테스트 |
| 권리 | 모든 상품·이미지에 출처와 사용 범위가 기록됨 | 데이터 감사 |
| 성능 | 로컬 seed 기준 검색 p95 300ms 이하 | 벤치마크 |
