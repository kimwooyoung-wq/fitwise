# [12주] 상품 카탈로그와 탐색

| 항목 | 내용 |
|---|---|
| 기간 | 2026-12-24 ~ 2026-12-30 |

## 목표

권리 문제가 없는 데이터로 검색·필터·추천 엔진이 사용할 상품 후보 집합을 만든다.

## 필수 과제

- [ ] 상품·옵션·사이즈 실측·가격·재고·스타일 태그 스키마 구현
- [ ] 합성 또는 사용 허가가 확인된 상품 100개 이상 seed
- [ ] 카테고리·가격·사이즈·스타일·재고 필터 구현
- [ ] 텍스트 검색과 페이지네이션 구현
- [ ] 데이터 출처와 합성 여부 표시
- [ ] 후보 검색 API 계약과 성능 기준 작성

## 선택 과제

- [ ] PostgreSQL 전문 검색과 단순 태그 검색 비교

## 산출물

- 상품 카탈로그 화면·API·seed
- `docs/architecture/product-catalog.md`
- 검색·필터 테스트

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 데이터 | 100개 이상, 필수 필드 누락 0건 | seed 검증 |
| 필터 | 조합 필터가 명세와 동일한 결과 반환 | API 테스트 |
| 사실성 | 가격·재고·실측이 생성형 출력에서 오지 않음 | 코드 리뷰 |
| 성능 | 로컬 seed 기준 검색 p95 300ms 이하 | 벤치마크 |
