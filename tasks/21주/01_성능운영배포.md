## 목표

재현 가능한 운영 배포와 기본 모니터링을 마련하고 사용자에게 안정적인 데모를 제공한다.

## 필수 과제

- [ ] 웹·API·DB 운영 환경과 최소 권한 설정
- [ ] main 병합 기반 자동 배포와 롤백 절차 구성
- [ ] 응답 시간·오류율·LLM 비용·실패율 모니터링
- [ ] 핵심 페이지 성능과 이미지·쿼리 최적화
- [ ] 백업·복구·장애 대응·데이터 삭제 런북 작성
- [ ] 이용 약관이 아닌 프로젝트 데이터·개인정보 안내 페이지 공개
