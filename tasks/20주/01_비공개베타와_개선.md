## 목표

실제 사용자 행동으로 제품 가설과 핵심 지표를 검증하고 출시 전 가장 큰 문제를 수정한다.

## 필수 과제

- [ ] 목표 사용자 8명 이상에게 동일한 구매 결정 과제 제공
- [ ] 기존 방식 기준선과 FITWISE 사용 결과 측정
- [ ] 결정 시간·확인 상품 수·선택 확신도·근거 이해도·완료율 수집
- [ ] 관찰과 사후 인터뷰로 실패 이유 수집
- [ ] 문제를 빈도·심각도·지표 영향으로 우선순위화
- [ ] 상위 3개 문제 수정 후 회귀 테스트

## 선택 과제

- [ ] 1주 후 선택 유지 여부 후속 인터뷰
