## 목표

자연어 구매 목적을 검증 가능한 구조화 조건으로 바꾸고 사용자가 추천 전에 수정할 수 있게 한다.

## 필수 과제

- [ ] occasion·budget·styles·avoid·required_categories 스키마 확정
- [ ] LLM 기반 파서와 규칙 기반 검증·정규화 구현
- [ ] 파싱 실패·모호함·지원하지 않는 조건 처리
- [ ] 구조화 결과 확인·수정 UI 구현
- [ ] 대표·경계·악의적 입력 평가셋 50개 이상 작성
- [ ] 프롬프트 인젝션을 실행 명령이나 신뢰 데이터로 취급하지 않도록 방어

## 선택 과제

- [ ] 규칙 기반 기준선과 LLM 파서 정확도·비용 비교

- 의도 파서 API와 조건 확인 화면

| 항목 | 통과 조건 | 확인 방법 |
