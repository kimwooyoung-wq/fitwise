# [16주] Decision Board와 명시적 피드백

| 항목 | 내용 |
|---|---|
| 기간 | 2027-01-21 ~ 2027-01-27 |
| 단계 | Decision Engine |
| 이슈 | 미등록 |

## 목표

사용자가 후보를 같은 기준으로 비교하고 우선순위를 바꿔 자신의 결정을 내릴 수 있게 한다.

## 필수 과제

- [ ] 최대 3개 후보의 가격·목적·사이즈·옷장·근거 비교 UI 구현
- [ ] 기준별 가중치 조정과 순위·설명 재계산 구현
- [ ] 저장·제외·더 저렴하게·더 개성 있게 피드백 구현
- [ ] 클릭만으로 취향을 확정하지 않고 명시적 피드백을 구분 저장
- [ ] 최종 후보 선택과 결정 완료 이벤트 기록
- [ ] 모바일 비교 방식과 접근성 구현

## 선택 과제

- [ ] 기본 가중치와 사용자 조정값의 차이 시각화

## 산출물

- Decision Board 화면·API
- 피드백 데이터 모델과 이벤트
- 비교·재정렬 E2E 테스트

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 재계산 | 가중치 변경 시 서버 계산과 UI 순위가 일치 | 통합 테스트 |
| 비교 | 핵심 기준과 근거·주의점을 한 흐름에서 확인 | 모바일 수동 점검 |
| 피드백 | 모든 명시적 피드백이 사용자·세션·후보와 연결 | DB·API 테스트 |
| 측정 | 결정 완료 시간과 최종 선택 이벤트가 중복 없이 기록 | 이벤트 테스트 |

## 다음 주 진입 조건

추천→비교→최종 선택 흐름과 이벤트 수집이 통과해야 한다.
