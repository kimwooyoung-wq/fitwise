# tasks/ — FITWISE 주차별 과제

이 폴더는 약 5개월간 진행하는 FITWISE의 실행 계획 원본이다. 큰 방향은 `README.md`의 로드맵이 설명하고, 실제로 이번 주 무엇을 끝내야 하는지는 이 폴더가 정의한다.

## 운영 방식

1. 작업을 시작할 때 [CURRENT.md](CURRENT.md)에서 현재 주차를 확인한다.
2. 해당 주차 파일의 목표, 필수 과제, 완료 기준을 읽는다.
3. 한 주 작업은 하나의 브랜치와 하나의 PR을 기본으로 한다.
4. 완료 기준을 모두 확인한 뒤 결과와 근거를 PR 본문에 남긴다.
5. 수요일 회고 후 `CURRENT.md`를 다음 주로 갱신한다.

## 주간 리듬

| 시점 | 활동 |
|---|---|
| 목요일 | 지난주 회고, 이번 주 범위 확정, 브랜치 생성 |
| 금~월요일 | 조사·설계·구현 |
| 화요일 | 테스트, 문서화, 범위 조정 |
| 수요일 | 완료 기준 점검, PR 제출, 회고 |

## 과제 파일 형식

- `목표`: 이번 주가 끝났을 때 달라져 있어야 하는 상태
- `필수 과제`: 반드시 끝내야 하는 범위
- `선택 과제`: 필수 과제를 끝낸 뒤에만 수행하는 범위
- `산출물`: 저장소에 남길 파일 또는 실행 가능한 기능
- `완료 기준`: 명령, 문서 검토, 사용자 테스트 등으로 확인 가능한 통과 조건
- `다음 주 진입 조건`: 핵심 의사결정이 끝나지 않았을 때 무리하게 다음 단계로 넘어가지 않기 위한 게이트

## 진행 상태

과제 문서의 체크박스는 계획 원본이므로 직접 완료 표시하지 않는다. 진행 상태는 각 주 PR과 GitHub Issue에서 관리한다. 이슈 제목은 `[N주] 과제명`, 본문에는 과제 파일 링크와 마감을 기록한다.
