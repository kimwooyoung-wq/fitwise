# FITWISE 22주 실행 로드맵

기간: **2026-10-08 ~ 2027-03-10** (22주, 약 5개월)

## 목표

문제 가설만 있는 현재 상태에서 출발해, 실제 사용자 검증을 거친 모바일 우선 웹 MVP를 공개하고 의사결정 시간·선택 확신도·추천 근거 이해도를 측정한다.

## 단계별 일정

| 단계 | 주차 | 핵심 결과 |
|---|---:|---|
| 1. Product Discovery | 1~4주 | 인터뷰, 경쟁 분석, 문제 우선순위, PRD |
| 2. Prototype | 5~7주 | 핵심 흐름, 비주얼 시스템, 사용성 검증 |
| 3. Foundation | 8~12주 | 개발 환경, 인증·프로필, 상품·옷장 데이터 |
| 4. Decision Engine | 13~16주 | 의도 파싱, 추천 점수, 근거·신뢰도, 비교 보드 |
| 5. Review Lens & Integration | 17~18주 | 유사 체형 후기 요약, 전체 흐름 통합 |
| 6. Validation & Launch | 19~22주 | 품질·보안, 베타 테스트, 배포, 데모·회고 |

## 공통 원칙

- 실제 쇼핑몰의 상품·리뷰를 무단 수집하지 않는다. 허가된 공개 자료나 합성 데이터를 사용한다.
- 가격·재고·사이즈 같은 사실은 생성형 AI가 만들지 않는다.
- 추천 점수 계산과 생성형 설명을 분리하고, 설명은 계산된 근거만 사용한다.
- 신체 정보는 최소 수집하며 로그와 분석 이벤트에 원문을 남기지 않는다.
- 기능 완성보다 매주 확인 가능한 사용자 가치와 근거를 우선한다.
