# [15주] 추천 근거와 신뢰도

| 항목 | 내용 |
|---|---|
| 기간 | 2027-01-14 ~ 2027-01-20 |
| 단계 | Decision Engine |
| 이슈 | 미등록 |

## 목표

각 추천에 왜 적합한지, 무엇이 불확실한지, 어떤 점을 주의해야 하는지 제공한다.

## 필수 과제

- [ ] 계산 근거를 설명 입력으로 변환하는 evidence schema 구현
- [ ] 추천 이유·주의점·부족한 정보·신뢰도 구성 구현
- [ ] 신뢰도를 데이터 완전성·일관성·최신성으로 계산
- [ ] LLM 설명이 제공된 근거 밖의 사실을 추가하지 않는 검증 구현
- [ ] 설명 생성 실패 시 구조화된 근거로 fallback
- [ ] 추천 결과 화면에 근거를 점수보다 우선해 표시

## 선택 과제

- [ ] 템플릿 설명과 LLM 설명의 이해도 비교 테스트

## 산출물

- evidence composer와 추천 결과 UI
- `docs/architecture/evidence-and-confidence.md`
- 근거 일치 평가셋

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 근거 일치 | 평가셋에서 근거 없는 사실 0건 | 자동·수동 평가 |
| 불확실성 | 데이터 부족 시 신뢰도가 낮아지고 부족 항목 표시 | fixture 테스트 |
| 복원력 | LLM 장애 시에도 추천과 구조화 근거 제공 | 장애 테스트 |
| 이해도 | 내부 테스트 참가자 5명 중 4명 이상이 주요 이유 설명 | 짧은 테스트 |
