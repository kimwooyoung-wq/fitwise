## 목표

명시적 필터와 결정적 점수 계산으로 서로 다른 세 가지 추천 전략을 만든다.

## 필수 과제

- [ ] 예산·재고·카테고리·제외 속성·사이즈 hard filter 구현
- [ ] 목적·옷장·사이즈·선호·예산·리뷰 점수 함수 구현
- [ ] 점수 구성 요소와 가중치를 응답에 포함
- [ ] Safe·Balanced·Bold 전략별 선택 규칙 구현
- [ ] 후보 부족 시 조건을 몰래 완화하지 않는 응답 구현
- [ ] 고정 fixture 기반 결정성·필터 위반·다양성 테스트 작성

## 선택 과제

- [ ] 초기 가중치 민감도 분석 노트 작성

## 산출물

- 추천 엔진과 API

| 항목 | 통과 조건 | 확인 방법 |
