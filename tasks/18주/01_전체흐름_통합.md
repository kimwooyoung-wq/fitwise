## 목표

온보딩부터 최종 결정과 피드백까지 모든 핵심 기능을 실제 API와 DB로 연결한다.

## 필수 과제

- [ ] 목·임시 데이터 호출을 실제 API로 교체
- [ ] 온보딩→목적 입력→옷장→추천→근거→비교→결정 흐름 연결
- [ ] 인증 만료·네트워크 실패·후보 부족·LLM 실패 복구 구현
- [ ] 추천 세션의 입력·계산 버전·결과·피드백 연결
- [ ] 핵심 여정 Playwright E2E 작성
- [ ] 분석 이벤트가 계획대로 수집되는지 검증

## 선택 과제
