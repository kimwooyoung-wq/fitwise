# [17주] Review Lens

| 항목 | 내용 |

| 이슈 | 미등록 |

## 목표

유사 체형 사용자의 경험을 우선해 핏·길이·소재·색감 정보를 근거와 함께 요약한다.

## 필수 과제

- [ ] 권리 문제가 없는 합성 리뷰와 체형 메타데이터 seed 작성
- [ ] 최소 정보 기반 유사 체형 매칭과 익명화 규칙 구현
- [ ] 핏·길이·소재·색감 속성 추출·집계 구현
- [ ] 리뷰 수·일관성·최신성을 신뢰도에 반영
- [ ] 요약에서 원문 근거로 이동할 수 있는 연결 제공
- [ ] 리뷰 부족·상충·편향 가능성 표시

## 선택 과제

- [ ] 임베딩 검색과 규칙 기반 검색의 정확도·비용 비교

## 산출물

- Review Lens API와 UI
- 합성 리뷰 데이터·평가셋
- `docs/architecture/review-lens.md`

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 추적성 | 모든 요약 문장이 원문 리뷰 ID와 연결 | 자동 검사 |
| 검색 | 평가셋에서 유사 체형 검색 Precision@5 0.8 이상 | 평가 스크립트 |
| 불확실성 | 리뷰 부족·상충 시 경고와 낮은 신뢰도 표시 | fixture 테스트 |
| 개인정보 | 리뷰 원문과 응답에 직접 식별 정보 없음 | 정적·수동 검사 |
