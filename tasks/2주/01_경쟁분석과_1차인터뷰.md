# [2주] 경쟁 분석과 1차 사용자 인터뷰

| 항목 | 내용 |
|---|---|
| 기간 | 2026-10-15 ~ 2026-10-21 |
| 단계 | Product Discovery |
| 이슈 | 미등록 |

## 목표

기존 서비스가 해결하는 문제와 놓치는 지점을 파악하고 실제 구매 행동의 증거를 수집한다. 기능 복제 목록이 아니라 FITWISE를 반드시 사용할 이유, 재방문 구조와 초기 사업 기회를 도출한다.

## 필수 과제

- [ ] 국내외 패션 탐색·사이즈 추천·코디 서비스 6개 이상 비교
- [ ] 각 서비스에서 동일한 구매 과제를 수행하고 단계 수·정보·설명·외부 이동을 기록
- [ ] 추천 기준·플랫폼 종속성·옷장 연속성·신뢰·재방문·수익 구조를 동일 기준으로 비교
- [ ] 반복되는 미해결 문제 3개와 FITWISE 차별화 문장·반증 조건 작성
- [ ] 초기 수익 모델 가설 1개와 프로토타입에서 측정할 사업 지표 정의
- [ ] 사용자 인터뷰 5명 수행
- [ ] 개인 식별 정보 없이 관찰·인용·해석을 분리해 기록
- [ ] 매 인터뷰 후 새로 확인·기각·추가된 가설 갱신

## 선택 과제

- [ ] 서비스별 모바일 접근성과 개인정보 수집 범위 비교

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 경쟁 분석 | 6개 이상, 동일한 평가 기준 10개 이상 | 비교표 검토 |
| 차별화 | 반드시 사용할 이유와 기존 서비스 대비 미해결 지점이 행동 근거와 연결됨 | 차별화 문장·반증 조건 검토 |
| 사업성 | 수익 가설이 상품 이동·반복 사용·지불 의향 중 하나 이상의 측정 행동과 연결됨 | 가설·지표 검토 |
| 인터뷰 | 5명 완료, 각 기록에 행동·문제·현재 대안 포함 | 익명 요약 검토 |
| 증거 | 핵심 주장마다 출처 인터뷰 수가 표시됨 | 요약 문서 검토 |
