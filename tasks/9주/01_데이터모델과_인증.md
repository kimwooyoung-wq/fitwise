# [9주] 데이터 모델과 인증

| 항목 | 내용 |
|---|---|
| 기간 | 2026-12-03 ~ 2026-12-09 |
| 단계 | Foundation |
| 이슈 | 미등록 |

## 목표

최소 개인정보 원칙을 반영한 데이터 모델과 안전한 로그인 기반을 만든다.

설계 기준선은 [`docs/architecture/database-design-and-sql.md`](../../docs/architecture/database-design-and-sql.md)이며, 이 주차에는 문서의 SQL 초안을 실제 migration·RLS·통합 테스트로 검증하고 차이를 다시 문서에 반영한다.

## 필수 과제

- [ ] 사용자·프로필·옷장·상품·리뷰·추천 세션·피드백 ERD 작성
- [ ] Supabase 인증과 세션 처리 구현
- [ ] 사용자 소유 데이터에 RLS 정책 적용
- [ ] 마이그레이션과 합성 seed 데이터 작성
- [ ] 계정 삭제 시 사용자 데이터 처리 정책과 기능 구현
- [ ] 민감 필드가 로그·분석 이벤트에 남지 않는지 점검

## 선택 과제

- [ ] 소셜 로그인 1종 추가

## 산출물

- `docs/architecture/database-design-and-sql.md`의 검증된 데이터 사전·ERD·SQL 계약
- DB 마이그레이션·RLS 정책·seed
- 로그인·로그아웃·계정 삭제 흐름

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
|---|---|---|
| 격리 | A 사용자가 B 사용자의 데이터에 접근 불가 | 통합 테스트 |
| 재현성 | 빈 DB에 마이그레이션과 seed 적용 성공 | 자동화 명령 |
| 인증 | 로그인·로그아웃·만료 세션 처리 동작 | E2E 테스트 |
| 삭제 | 계정 삭제 후 정책대로 데이터 제거 또는 익명화 | DB 확인 |
| CRUD | 저장·단건/목록 조회·검색·동시 수정·삭제 흐름이 소유권 조건과 함께 동작 | repository 통합 테스트 |
| 검색 | 필수 조건·최신성·pagination을 지키고 대표 쿼리 실행 계획을 기록 | `EXPLAIN (ANALYZE, BUFFERS)` |
