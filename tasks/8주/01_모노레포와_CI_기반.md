## 목표

웹·API를 누구나 같은 방법으로 실행하고 변경을 자동 검증할 수 있는 개발 기반을 만든다.

## 필수 과제

- [ ] Next.js·TypeScript·Tailwind 웹과 FastAPI API 기본 구조 생성
- [ ] 린트·포맷·타입 검사·단위 테스트 명령 통일
- [ ] Docker Compose로 PostgreSQL·pgvector 로컬 환경 구성
- [ ] `/health` 엔드포인트와 웹 상태 확인 화면 구현
- [ ] GitHub Actions에서 웹 빌드와 API 테스트 실행
- [ ] `.env.example`, 로컬 실행, 문제 해결 방법 문서화

## 선택 과제

- [ ] 개발용 seed 명령과 pre-commit hook 추가

## 완료 기준

| 항목 | 통과 조건 | 확인 방법 |
