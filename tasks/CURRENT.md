설문은 2026-10-12에 최종 21건으로 종료했으며 [최종 분석](../docs/research/survey-results.md)에서 핵심 문제와 프로토타입 우선순위를 확정했다. 목표 30건보다 작은 편의표본이므로 시장 전체로 일반화하지 않고 경쟁 분석과 5인 과업 테스트로 행동 근거를 보완한다.

## 우선순위 변경 · DB/RLS 초기 검증을 앞당김

- 경쟁 서비스 동일 과업 비교와 실기기 검증은 **대기**한다. 미완료 상태를 유지하고 3주차 행동 검증 설계의 진입 근거로 계산하지 않는다.
- 사용자가 데이터 안전성과 상품 연동 기반을 우선 요청하여 원래 9주차의 일부를 [Issue #5](https://github.com/kimwooyoung-wq/fitwise/issues/5) 초기 기술 스파이크로 앞당겼다.
- 초기 범위는 로컬/CI PostgreSQL migration, 사용자 데이터 RLS 격리, 합성 카탈로그, 출처 권한·최신성 게이트다. 이는 9주차 전체 완료가 아니며 이번 이슈의 PR이 통과되기 전까지 완료로 표시하지 않는다.
- **실제 상품 피드/API 연결은 아직 불가**: 공식 브랜드/판매처 공급원, 계약상 저장·표시 권리, 테스트 계정이 정해지지 않았다. 이 전에는 크롤링하지 않고 합성 데이터만 쓴다.
- 이번 조정은 계획 변경이지 검증 통과가 아니므로 주차·전체 진행률을 올리지 않는다.

단, 사용자 흐름 검증을 앞당기기 위한 `검색 → 추천 결과` 기술 프로토타입은 합성 데이터로 병행한다. 프로토타입 결과를 제품 가치가 검증된 것으로 해석하거나 실제 브랜드 상품을 연결하지 않는다.

## 대기된 Discovery 게이트와 별도 확인 항목

1. PR #2와 PR #4 사람 검토·병합 결정은 여전히 사용자 승인 대기이며 본 DB 작업과 분리한다.
2. Android/iOS 프로토타입 정상·빈 결과·오류·재시도 스모크 테스트는 대기 중이며 앱 전체 최종 검토로 해석하지 않는다.
3. [사람 검증 실행표](../docs/research/human-validation-runbook.md)의 경쟁 서비스 동일 과업 비교는 사용자가 재개할 때까지 보류한다.
4. 5인 사용성 테스트 후 MVP PRD와 데이터 사전·ERD를 확정한다. DB 초기 스파이크는 사용자 가치 검증을 대체하지 않는다.

## 진행률 기준

진행률은 작성한 코드나 파일 수가 아니라 각 주차의 필수 산출물·완료 조건·검증 증빙으로 계산한다. 열린 PR과 선행 기술 프로토타입은 검수와 해당 게이트가 끝나기 전까지 다음 주차 완료로 앞당겨 계산하지 않는다.

| 범위 | 산식 | 현재 진행률 | 해석 |
|---|---:|---:|---|
| 전체 22주 | 주차별 게이트 충족도 합계 ÷ 22 | **4%** | 1주차 0.9, 2~22주차 0으로 계산한 4.1%의 반올림 |
| Discovery 1~4주 | Discovery 주차 게이트 충족도 합계 ÷ 4 | **23%** | 0.9 ÷ 4 = 22.5%의 반올림 |
| 현재 2주차 | 필수 산출물·검증·승인 상태 | **0% 통과** | 경쟁 서비스 비교를 대기했으며 통과 증빙 없음. 별도 DB/RLS 스파이크는 주차 완료율에 합산하지 않음 |

1주차는 PR 제출과 자동 검사가 완료됐어도 승인·병합 전이므로 `통과`가 아니라 `제출` 상태다. 경쟁 서비스 실제 비교는 2주차 과제이며 현재 보류 상태다. 대상과 프로토콜 문서만으로 비교 과제가 끝난 것으로 보지 않는다.
